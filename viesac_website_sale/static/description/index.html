01 / LIVE CHECKOUT

A real VAT check in the real checkout.

The extension adds a status indicator to the customer’s Tax ID field.

  • Use your VIESAC API key from the main compliance module.
  • Display VALID, INVALID, PENDING or UNVERIFIED according to the actual result.
  • Quick validation does not return a company name or address. It does not create an audit certificate.

One connected workflow

Checkout now. Full evidence in the back office.

VIESAC VAT Compliance

The required main module provides contacts, VAT/EORI audits, orders, invoices, certificates and the rates catalog.

VIESAC eCommerce

The optional extension adds the VAT status indicator to website_sale. EORI checks remain in the back office.

Tax configuration

Your tax rules stay in Odoo.

Tax treatment follows the store’s configured fiscal positions, addresses and accounting localization. The status request does not change the cart’s fiscal position or automatically apply 0% VAT.

  • Requires Odoo 16, website_sale and viesac_vat_compliance.
  • Without an API key, a successful format check is shown as UNVERIFIED.
  • Government service availability and API limits can affect response time.
